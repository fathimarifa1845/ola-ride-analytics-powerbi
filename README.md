# 🚖 Ola Ride Analytics Dashboard

## 📌 Project Overview

An interactive Power BI dashboard developed to analyze **103,024+ ride booking records** and generate insights into ride demand, revenue, customer behavior, vehicle performance, cancellations, and service quality.

The dashboard transforms raw ride data into interactive visualizations and KPIs to support data-driven business decisions.

## 🎯 Objectives

- Analyze ride booking trends and ride frequency.
- Monitor booking status and cancellation patterns.
- Evaluate vehicle-wise ride performance.
- Analyze total booking value and revenue patterns.
- Understand customer spending and payment preferences.
- Monitor customer and driver ratings.
- Generate actionable business insights for operational improvement.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Key KPIs

- Total Bookings
- Total Booking Value
- Average Ride Distance
- Average Customer Rating
- Average Driver Rating
- Cancellation Rate

## 📈 Dashboard Analysis

The dashboard includes:

- Ride Volume Over Time
- Booking Status Breakdown
- Top Vehicle Types by Ride Distance
- Average Customer Ratings by Vehicle Type
- Cancellation Reasons
- Revenue by Payment Method
- Top Customers by Booking Value
- Ride Distance Distribution
- Driver Rating Distribution
- Customer vs Driver Ratings

## 🔍 Key Insights

- Identified ride booking patterns and demand fluctuations over time.
- Analyzed high-value customer spending behavior.
- Evaluated digital payment preferences.
- Compared vehicle categories based on ride distance and performance.
- Identified cancellation patterns and potential areas for improvement.
- Analyzed customer and driver rating trends.

## 💡 Business Recommendations

- Increase driver availability during peak demand periods.
- Promote digital payment methods.
- Monitor and improve driver service quality.
- Focus on high-value customer retention.
- Optimize premium ride availability to improve revenue.
